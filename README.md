# 🚀 Trinetra Internship Management Portal

A modern, responsive **Internship Management Portal** built with **React.js** that streamlines the internship application process for students and administrators. The platform focuses on a clean user experience, secure authentication, and efficient internship management.

🌐 **Live Demo:** https://trinetra-hub.vercel.app/

---

## 📌 Overview

The Trinetra Internship Management Portal was developed to simplify internship registration and application management through an intuitive and responsive web interface. The project demonstrates modern frontend development practices using React.js while emphasizing scalability, maintainability, and user experience.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/prajwalkarajange/trinetra-technology-pmr.git
```

### Navigate to the project

```bash
cd trinetra-technology-pmr
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
